* llm-context.el
:PROPERTIES:
:CUSTOM_ID: llm-contextel
:END:
Copy Emacs context in a format useful to LLM coding tools.

=M-x llm-context-copy= copies a reference and optional source text. For
temporary, non-file, non-web buffers it uses an =emacs-context=
reference and adds a block describing the current Emacs state.

** Installation
:PROPERTIES:
:CUSTOM_ID: installation
:END:
#+begin_src elisp
(use-package llm-context
  :ensure t
  :bind (("C-c y c" . llm-context-copy)))
#+end_src

Doom Emacs:

#+begin_src elisp
(package! llm-context
  :recipe (:host github :repo "unship/llm-context.el"))
#+end_src

Run =doom sync= after adding the package. Then restart the daemon.

** Basic file buffers
:PROPERTIES:
:CUSTOM_ID: basic-file-buffers
:END:
Run =M-x llm-context-copy= with point on one line:

#+begin_src text
~/src/app.el:42

```emacs-lisp
(message "hello")
```
#+end_src

Select lines 10 through 14 to copy a range:

#+begin_src text
~/src/app.py:10-14

```python
def answer():
    return 42
```
#+end_src

Selections ending at the beginning of the next line exclude that next
line. Selections longer than =llm-context-max-lines= (100 by default)
omit the source block. Use =C-u M-x llm-context-copy= to force it back
in.

** Org-mode
:PROPERTIES:
:CUSTOM_ID: org-mode
:END:
Org buffers keep the normal file reference, but add the surrounding Org
outline path so the copied line has document context. The line number after
each headline is the headline's actual line in the file, not a hierarchy ID.
For this buffer:

#+begin_example
1 * Project
2 ** Architecture
3 A design note.
#+end_example

Copying line 3 produces:

#+begin_example
~/notes/design.org:3 — Project (lines 1-3) / Architecture (lines 2-3)
#+end_example

When point is inside an Org source block, the complete block is copied and
its actual language is used for the Markdown fence. The current point line
and headline definition lines remain separate. For example, with the source
block beginning on line 3:

#+begin_example
~/notes/design.org:3 — Project (lines 1-3) / Architecture (lines 2-3)

#+begin_src python
print(42)
#+end_src
#+end_example

Selecting a region in an Org buffer keeps the normal selection behavior. The
reference still includes the surrounding headline path and its definition
lines. The source-block behavior applies only when there is no active region;
an over-limit source block is omitted unless a prefix argument is supplied.

** Dired and Dirvish
:PROPERTIES:
:CUSTOM_ID: dired-and-dirvish
:END:
With files marked, each path is copied on its own line:

#+begin_src text
~/src/app.el
~/src/lib/util.py
#+end_src

With no marks, the file at point is copied. If point is not on a file,
the current directory is copied.

** EWW
:PROPERTIES:
:CUSTOM_ID: eww
:END:
Without a region, EWW copies only the URL:

#+begin_src text
https://example.com/article
#+end_src

With text selected in the rendered page, it copies the URL and selected
text:

#+begin_src text
https://example.com/article

```text
The selected paragraph from the page.
```
#+end_src

** Magit
:PROPERTIES:
:CUSTOM_ID: magit
:END:
At a Magit hunk, it copies a unified diff and its source reference:

#+begin_src text
~/src/app.el (unstaged)

```diff
@@ -42,1 +42,1 @@
-old value
+new value
```
#+end_src

Staged and untracked files use =(staged)= and =(untracked)=. A commit
view includes SHA and subject:

#+begin_src text
~/src/app.el @ e63a038 — fix parser error
#+end_src

A range view uses:

#+begin_src text
~/src/app.el @ main..feature/parser
#+end_src

A diff longer than the configured limit is copied without its diff body.
Use a prefix argument to include it.

** Result buffers with source locations
:PROPERTIES:
:CUSTOM_ID: result-buffers-with-source-locations
:END:
Compilation, grep, xref, occur, and plain diff buffers use the source
file and line when Emacs can resolve one:

#+begin_src text
~/src/parser.py:87

```python
raise ParseError(token)
```
#+end_src

If no source location is available, the command falls back to the result
buffer's =emacs-context= reference and its current line or selected
region.

** Help and documentation
:PROPERTIES:
:CUSTOM_ID: help-and-documentation
:END:
*** help-mode and helpful-mode
:PROPERTIES:
:CUSTOM_ID: help-mode-and-helpful-mode
:END:
These are temporary, non-file buffers, so the reference uses Emacs
context. The symbol at point and its current line (or selection) are
copied:

#+begin_src text
emacs-context:*Help*

```text
Return the file name of the current buffer, or nil.
```
#+end_src

*** Info-mode
:PROPERTIES:
:CUSTOM_ID: info-mode
:END:
Info uses an Emacs context reference while preserving the current Info
file and node in the buffer state:

#+begin_src text
emacs-context:*info*

```text
Buffers are objects that hold text to be edited.
```
#+end_src

*** Man-mode and woman-mode
:PROPERTIES:
:CUSTOM_ID: man-mode-and-woman-mode
:END:
The manual page is a temporary buffer, so it uses Emacs context:

#+begin_src text
emacs-context:*Man git-commit*

```text
git commit - Record changes to the repository
```
#+end_src

** Shell and status buffers
:PROPERTIES:
:CUSTOM_ID: shell-and-status-buffers
:END:
=shell-mode=, =eshell-mode=, =term-mode=, and =comint-mode= use an
=emacs-context= reference and copy the current command/output line or
selected region:

#+begin_src text
emacs-context:*shell*

```sh
git status --short
```
#+end_src

=messages-buffer-mode=, =debugger-mode=, and =backtrace-mode= use an
=emacs-context= reference and copy the current line or selection:

#+begin_src text
emacs-context:*Backtrace*

```text
  my-function(arg)
```
#+end_src

=package-menu-mode=, =ibuffer-mode=, =tabulated-list-mode=,
=vc-dir-mode=, =org-agenda-mode=, and =calendar-mode= also use an
=emacs-context= reference and copy the current row/entry or selected
region:

#+begin_src text
emacs-context:*Packages*

```text
U  magit   4.3.0   A Git porcelain inside Emacs
U  gptel   0.9.8   A large language model chat client
```
#+end_src

** Emacs internal context
:PROPERTIES:
:CUSTOM_ID: emacs-internal-context
:END:
For a temporary, non-file, non-web buffer such as =helpful-mode=, the
reference is an Emacs context instead of a fake =buffer:line= path:

#+begin_src text
emacs-context:*Help*

```text
describe-variable: buffer-file-name
```

```emacs-context
daemon: doom
buffer: *scratch*
major-mode: emacs-lisp-mode
minor-modes: evil-local-mode, company-mode
point: 18
narrowed: no
help-object: buffer-file-name
```
#+end_src

The daemon value comes from =daemonp=: it is the daemon name for a
daemon client, and =none= for a regular Emacs process. Disable the block
if only the reference and source text are wanted:

#+begin_src elisp
(setq llm-context-include-emacs-context nil)
#+end_src

:CUSTOM_ID: configuration
